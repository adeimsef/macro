# Imperial Macro

Standalone static HTML + CSS landing page for Imperial Macro.

## Deploy to GitHub and Vercel

1. Download and unzip this folder.
2. Create a new GitHub repository.
3. Upload everything inside this folder, including `index.html`, `style.css`, `vercel.json`, and `public/`.
4. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.

No build command or package installation is required. Vercel serves `index.html` directly.

The newsletter links point to the Imperial Macro Substack subscribe page. Social links point to `@imperialmacro` on X, Instagram, Telegram, Facebook, and LinkedIn.

## Notes

- This export is intentionally standalone. It does not depend on React, npm packages, Replit workspace packages, or hidden Replit configuration.
- The `.gitignore` file only excludes dependencies, build output, local environment files, and OS metadata. It does not hide the source files from GitHub.
